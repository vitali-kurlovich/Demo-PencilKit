

# Функциональные требования

 ## Галерея уроков
 Галерея отображает список доступных уроков. 
 Если файлы уроков распологаются на сервере, то на этом экране должна быть поддержка различных состояний экрана:
  - Состояние когда нет доступных уроков
  - Состояние загрузки списка уроков
  - Состояние загрузки конкретного урока
  - Состояние когда всё загружено

 
 ## Режим прохождения урока
 
### Урок

Уроки могут предствлять собой отработку конкретных навыков (рисование линий, закрашивание фигур, подбор цвета), так и комплексное занятие включающее пошаговое рисование выбранного рисунка


Урок с пошаговым рисованием состоит из 2-х этапов:
 - Поэтапная закраска, когда шаг за шагом закрашиваются определённым цветом участки рисунка, начиная с крупных участков, заканчивая небольшими деталями
 - Поэтапное рисование контуров

 ## Рисование линий

На этапе урока, где требуется отрабатывать рисование линий, пользователю следует обозначить путь по которому должен пройти наконечник пера. Для привлечения внимания можно задействовать анимацию, как в примерах ниже

Для того, что-бы определить насколько точно пользователь нарисовал линию можно использовать [Расстояние Фреше](https://en.wikipedia.org/wiki/Fr%C3%A9chet_distance), данная метрика позволяет выяснить мерау сходства кривых. Для каждого шага урока можно выставить пороговое значение данной метрики, что-бы выяснить нужно ли повторить ещё раз данный шаг урока.

Релизацию вычисления можно посмотреть тут: [FrechetDistance.swift](https://github.com/vitali-kurlovich/swift-mathkit/blob/main/Sources/MathKit/Measurment/FrechetDistance/FrechetDistance.swift)

# Нефункциональные требования

 ## Производительность
  Для использования стилуса предъявляются высокие требования по производительности, поскольку любое отставание от рисуемой линии от наконечника стилуса вызывает высокий дискомфорт у пользователя. 
  При проектировании иерархии экрана следует избегать большого скопления ui-элементов в области рисования, особенно полупрозрачных, поскольку это будет приводит к высокой нагрузуке на CPU/GPU при компоузе интерфейса.

  Следует уделить внимание профилированию производительности, получению метрик, например с помощю [OSSignposter](https://developer.apple.com/documentation/os/ossignposter), и избегать оптимизаций без ориентации на метрики

  ## Расход места на SSD
  Следует обратить внимание на занимаемое место ресурсами, что-бы программа не попадала хотя-бы в десятку программ по использованию меств нв SSD, поскольку это может привести к отказу пользователя от использования программмы

  Для уменьшения занимаемого места на SSD можно слелать:
   - Оптимизировать по размеру файлы уроков
   - Загружать уроки динамически, по ходу использования программы и удаление рание пройденых, можно использовать [Background Assets](https://developer.apple.com/documentation/backgroundassets)
